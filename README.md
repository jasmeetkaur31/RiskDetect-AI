# RiskDetect AI

An AI-powered transaction risk detection platform built using Streamlit and Isolation Forest.

## Features

- Upload transaction CSV files
- Detect anomalous transactions
- Multiple detection modes
- Interactive dashboard
- Download risk reports

## Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn
- Plotly
